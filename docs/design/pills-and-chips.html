Pills and chips

The standard, agreed 2026-10-12 and in use from 2026.10.10-b7. Its one source is app/web/src/pills.css, which this page links: the standard and every Now column below are drawn by that file itself, so this page cannot drift from it. The admin UI's modules compose its classes; the cards and the Tablet Layout editor take it in through integration/cards/src/pills.ts, with HA's colours.

A pill shows a state; a chip is pressed. Each style has an Id to name it by; pills-and-chips.html#sw-chip jumps to and highlights its row. The Before columns are how each looked until then, copied, for the record. Hover and focus are drawn as states too, not only on hover. Light or dark follows your system setting, as the admin UI does. Example text is invented.

The standard

Colour comes from --tone: a tone class (cm-good, cm-accent, cm-warn, cm-bad, cm-muted, cm-bark) or a module's own. With none, a pill and an unpressed chip are muted, and a pressed chip takes the accent. A module composes the classes (composes: cm-pill cm-fixed from global) and adds only its tone or layout.
