Heating Flow Card

A playground: one card, three views, any installation. Invented sensors and numbers. Name to be agreed before coding.

Heating & hot water

Tap, hold or double-tap any reading or part.

How to read it

  • Colour is temperature. Each sensor sits at its own point on its pipe, and its reading is a stop in that pipe's gradient: a run that loses heat fades along its length. On the scale above, or by circuit (C1).
  • Chevrons are flow. They move only while that circuit flows, faster as its pump runs faster. Still water keeps its colour but dims.
  • Nothing fails silently. An unavailable sensor drops out of the gradient and shows how long it has been missing (try Fault); a quiet one is fine, and Sensor Watch judges silence. A pump that should be running and isn't is ringed amber.
  • Areas are generic. Source (borehole, ground loop or air, with optional PVT), plant room (heat pump, pumps, diverter, tank), house (floors of underfloor loops or radiators, taps). The area names are options; nothing is drawn that the config doesn't name.

Config sketch

type: custom:cm-heating-flow
view: system                         # system | heat_pump | rooms
range: [-5, 65]                      # the colour scale, °C
areas: [Outside, Plant room, House]
source:
  type: borehole                     # borehole | horizontal | air
  pump: sensor.brine_pump_speed
  pvt: { valve: binary_sensor.pvt_valve }        # optional, ground source only
heat_pump:
  priority: sensor.priority
  compressor: sensor.compressor_frequency
  calculated_supply: sensor.calculated_supply
  degree_minutes: sensor.degree_minutes
  outdoor: sensor.outdoor_temperature
  power: sensor.hp_power
  heat: sensor.hp_heat_output
  aux: sensor.aux_heater
  alarm: sensor.hp_alarm
  refrigerant: { suction: …, hot_gas: …, liquid: …, evaporating: …, condensing: … }
  reversing_valve: binary_sensor.defrost         # air source
heating:
  pump: sensor.heating_pump_speed
  diverter: sensor.diverter                      # heating | hot water
  floors:
    - name: Ground floor
      emitters: underfloor                       # underfloor | radiators
      mixing: { valve: …, pump: … }              # optional
      loops:
        - { name: Kitchen, actuator: binary_sensor.kitchen_actuator, climate: climate.kitchen, return: sensor.kitchen_loop_return }
dhw:
  tank: [sensor.tank_top, sensor.tank_middle, sensor.tank_bottom]
  flow: sensor.hot_water_flow
  recirculation: { pump: … }                     # optional
# Every temperature sensor names the pipe it sits on and where:
sensors:
  - { entity: sensor.brine_in,      pipe: brine_in,      at: 0.5 }
  - { entity: sensor.supply,        pipe: heating_supply, at: 0 }
  - { entity: sensor.house_supply,  pipe: heating_supply, at: 0.8 }   # after the run to the house
# any part: tap_action / hold_action / double_tap_action (default: more-info)
