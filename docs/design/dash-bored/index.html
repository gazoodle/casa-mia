Dash-Bored: the directions

Each page is a working mock-up of the same invented house at wall-tablet size (1340 × 800). Everything can be pressed: lights switch, scenes run and the page reacts. None of them talks to Home Assistant. Movement is rendered in 3D and needs an internet connection to load.

The label beside a name says how far the idea has got. A sketch shows an idea. A trial tries one part of another design. A designed page is worked out in enough detail to build from. An implemented one has been built into Dash-Bored, and its label adds how mature that build is, on the same scale as Casa Mia's applets. The page here is still the mock-up, not the build.
